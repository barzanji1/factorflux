Build a chat system between agents and carriers through the carrier portal.

Database

 Create portal_chats table: id, carrierId, portalUserId, agentId, createdAt
 Create portal_chat_messages table: id, chatId, senderType (agent/carrier), senderId, message, attachmentUrl (nullable), attachmentName (nullable), read (boolean, default false), createdAt
 Run db:push

Backend

 GET /api/portal/chat — carrier gets their own chat thread (requirePortalAuth)
 POST /api/portal/chat/messages — carrier sends message (requirePortalAuth)
 GET /api/portal/chat/messages — carrier fetches messages (requirePortalAuth)
 GET /api/carrier-chat/:carrierId — agent gets chat thread for a carrier (requireAuth)
 POST /api/carrier-chat/:carrierId/messages — agent sends message (requireAuth)
 GET /api/carrier-chat/unread-count — total unread messages across all carrier chats (requireAuth)
 All message endpoints poll-friendly — accepts ?since=timestamp to fetch only new messages
 File attachment support — agents and carriers can send PDFs and images
