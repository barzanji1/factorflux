# Production access and downloads

Staff login: https://factorflux.co/login

Carrier portal: https://factorflux.io/portal

Always share production links, never a browser preview address.

## Desktop access

Use https://factorflux.co/download for desktop access options.
The installation guide is available at
https://factorflux.co/api/desktop/download/guide.

Download endpoints require the corresponding installer package to be published:

- https://factorflux.co/api/desktop/download/windows
- https://factorflux.co/api/desktop/download/mac
- https://factorflux.co/api/desktop/download/linux

If an installer is unavailable, use the web application instead.
