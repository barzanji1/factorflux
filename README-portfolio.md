# Dosh Barzanji - Portfolio Website

A professional portfolio website showcasing software development expertise, with a focus on freight factoring systems and business applications.

## Features

- **Modern Design**: Clean, professional layout with responsive design
- **SEO Optimized**: Proper meta tags, Open Graph tags, and semantic HTML
- **Interactive Elements**: Smooth scrolling, animations, and hover effects
- **Contact Integration**: Direct email integration via mailto links
- **Project Showcase**: Featured projects including QuantumCore
- **Service Listings**: Comprehensive list of offered development services

## Sections

### 1. Hero Section
- Professional introduction
- Call-to-action buttons
- Animated elements

### 2. About Section
- Expertise overview
- Technology stack showcase
- Skills grid with icons

### 3. Portfolio Section
- **QuantumCore**: Featured freight factoring management system
- Additional project placeholders for future work
- Technology badges and live/demo links

### 4. Services Section
- Web Application Development
- Database Design
- Business Automation
- Specialized Freight Solutions

### 5. Contact Section
- Contact information
- Working contact form with email integration
- Professional credentials and benefits

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS, Custom CSS animations
- **Icons**: Font Awesome 6.0
- **Features**: Responsive design, Intersection Observer API
- **Contact**: Mailto integration for form submissions

## Key Highlights

- **QuantumCore Showcase**: Prominently features the freight factoring system
- **Professional Branding**: Consistent color scheme and typography
- **Industry Focus**: Specialized content for freight and logistics solutions
- **Contact Ready**: Immediate contact through multiple channels

The website is designed to be easily customizable:

- Add new services or skills as needed
