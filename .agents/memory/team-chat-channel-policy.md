---
name: Team Chat channel policy
description: Default channels, agent-created public channels, and user consent before removing conversation history.
---

Team Chat defaults are only #general and #operations. Agents may create their own named channels, shared with all staff just like the defaults.

**Why:** The user explicitly requested these two defaults and team-wide custom channel creation.

**How to apply:** Do not reintroduce #funding or #collections as defaults or make custom channels admin-only/private.

Before removing an old channel, check its actual message history. Empty channels may be removed; if any history exists, report it and wait for the user to decide whether to archive or delete.

**Why:** The user explicitly required this check to prevent losing messages.

**How to apply:** Preserve any channel containing messages until the user decides. Retirement is one-time maintenance, not recurring cleanup: agents may later reuse an old default name for a new custom channel.
