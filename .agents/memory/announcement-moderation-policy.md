---
name: Announcement moderation policy
description: Approval, expiration and dismissal decisions for shared dashboard announcements.
---

Ordinary agent edits require fresh approval, including edits to previously approved messages. Admins and managers may publish immediately; all approved announcements are shared across staff, not scoped to a manager's reporting team.

**Why:** The user requires agent submissions to be moderated before appearing on every agent dashboard. Allowing an approved message to be changed live would bypass that requirement.

**How to apply:** Treat approval as approval of the exact reviewed version. Retain authorship when a reviewer edits someone else's post, and reject stale reviews or edits.

The seven-day display lifetime begins at publication/approval. Persistent posts do not expire. Personal dismissals remain hidden after edits and reapproval, but authors and reviewers can still manage hidden/expired posts.

**Why:** A long approval wait should not use up the message's useful lifetime; the user explicitly says dismissed announcements stay hidden for that agent.

**How to apply:** Keep management history separate from the active feed. Send rejection notifications atomically with the rejection so an author is never silently rejected.
